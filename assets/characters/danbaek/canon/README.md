# Danbaek CANON — LOCKED

이 폴더는 사용자가 확정한 `단백이 성장 시스템 기본 이미지`를 최우선 시각 CANON으로 보존한다.

## 절대 규칙
- 새 캐릭터 디자인으로 재해석하지 않는다.
- 얼굴, 머리/몸 비율, 어깨/팔/다리 실루엣, 검은 외곽선, 흰색 몸, 약간 엉성한 손그림 느낌을 임의 변경하지 않는다.
- 3D/반실사/깔끔한 벡터 마스코트로 바꾸지 않는다.
- 성장 시스템은 기존 WORKOUT CORE / GROWTH ENGINE / BODY STATE ENGINE 계약을 변경하지 않는다.
- Stage 0 및 이후 성장 시각 구현은 `danbaek_growth_system_canon.webp`를 기준으로 맞춘다.

## 현재 자료
- `danbaek_growth_system_canon.webp`: 사용자가 직접 확정한 MASTER CANON 원본의 저장소용 고품질 사본.
- `manifest.json`: CANON 상태와 구현 규칙.
- 기존 SVG/stages 자료는 보조 참고이며 MASTER보다 우선할 수 없다.

## 구현 원칙
Codex는 이 이미지를 참고해 새 캐릭터를 디자인하는 것이 아니라, 기존 Renderer의 parametric Stage 0가 원본 실루엣을 최대한 재현하도록 맞춰야 한다. CANON과 코드가 충돌하면 임의 변경하지 말고 중단 후 보고한다.

## Stage 0 MASTER CANON — LOCKED

사용자가 승인한 `layered/danbaek_stage0_layered_master.svg`와 Renderer의 현재 Stage 0 외형을 MASTER CANON으로 고정한다.

- 머리와 얼굴은 성장하지 않는 캐릭터 정체성이다.
- Stage 0의 작고 둔하며 약간 엉성한 인상을 유지한다.
- Stage 0에 성장 단계용 근육선을 미리 추가하지 않는다.
- Stage 0 비율을 길쭉한 사람형, 이모티콘 머리 + 사람 몸, 깔끔한 벡터 마스코트로 재해석하지 않는다.

## Lv.1~Lv.10 성장 불변 규칙 — LOCKED

Lv.1~Lv.10은 키가 커지는 서로 다른 캐릭터가 아니라 동일한 단백이 몸에 근육량과 부피가 붙는 과정이다.

- 성장에 따른 전체 키 증가는 금지한다.
- 머리 크기, 눈/입 위치와 형태, 얼굴 중심 등 얼굴 정체성을 고정한다.
- 팔과 다리의 기본 길이를 고정한다. 성장은 길이가 아니라 굵기와 외측 곡률로 표현한다.
- 캐릭터 중심축을 고정한다.
- 어깨, 가슴, 등, 팔, 골반 주변, 허벅지, 종아리의 좌우 부피 증가를 성장의 핵심으로 사용한다.
- 근육선은 성장 단계와 definition에 따라 점진적으로 증가하며 낮은 단계에서는 최소화한다.
- 흰 몸, 검은 손그림 외곽선, 단순한 손/발, 약간 엉성하고 힘 빠진 인상을 모든 단계에서 유지한다.
- 단일 부위 성장 때문에 approved region 밖 실루엣이나 다른 부위 길이가 변하면 안 된다.
- Stage 1~10 구현 시에도 전신 일괄 scale이나 full-body SVG 교체로 개별 부위 성장을 대체하지 않는다.

### 성장 방향 검증 기준

원본 래스터의 Lv.1~Lv.10 외곽선을 전체 높이 대비 비교하면 머리와 사지 길이 변화는 작고, 어깨/가슴/골반 및 사지 굵기가 단계적으로 증가한다. 따라서 향후 Renderer 검수는 다음을 만족해야 한다.

1. 동일 파라미터 단계 간 전체 높이와 중심축이 유지된다.
2. 팔/다리 root와 끝점의 기본 세로 범위가 유지된다.
3. 성장량은 해당 approved region의 좌우 폭과 곡률에 우선 반영된다.
4. 근육선은 실루엣 성장보다 늦고 점진적으로 나타난다.
5. Lv.10에서도 MASTER CANON의 부피 상한과 손그림 정체성을 넘지 않는다.
