# 실기기 QA 절차 (갤럭시 / Android)

> V1 출시 전에 **사람이 직접 해야만 확인되는 것들**만 모았다. 자동 검증으로 이미 덮은 것은 넣지 않았다
> ([RELEASE_AUDIT.md](../RELEASE_AUDIT.md)의 E 항목과 같은 번호를 쓴다).
>
> 각 항목은 **무엇을 보면 통과인지**까지 적었다. 애매하면 통과로 치지 말고 그대로 적어 두면 된다.

## 0. 설치

1. APK를 내려받는다 — **첫 빌드(2026-08-25, v1.0.0 / versionCode 1)**:
   <https://expo.dev/artifacts/eas/SwLIVzJknhAlbr8rd85CncuFifXPIa1p6rPn_GuB6Qs.apk>
   (빌드 페이지: <https://expo.dev/accounts/usunge/projects/hellchang-grow/builds/626adae7-fd1d-4532-b3ea-4e68562a2922>)
   갤럭시에서 이 링크를 직접 열어 받는 것이 가장 빠르다. 이후 빌드는 프로젝트의 Builds 탭에서 받는다.
2. 갤럭시에서 "출처를 알 수 없는 앱 설치"를 허용하고 APK를 설치한다.
3. 홈 화면에서 앱 이름이 **헬창키우기**로 보이는지 확인한다(아이콘 아래 이름).

> 이 빌드는 개발용이 아니라 **release 모드로 컴파일된 APK**다. 광고 mock과 DEV 구독 버튼은
> 들어 있지 않아야 한다 — 아래 `E7`에서 확인한다.

---

## E1. 세션 중 앱 강제 종료 → 복구

1. [운동 시작] → 아무 부위나 골라 세션을 시작한다.
2. 세트를 **하나 이상 완료**한다(저장이 일어난다). 타이머 시간을 적어 둔다.
3. 앱을 백그라운드로 보내고 **앱 전환기에서 강제 종료**한다.
4. **30분 이상** 기다린 뒤 앱을 다시 켠다.
5. **통과 기준**: 세션이 남아 있고 상태가 [일시정지]이며, 경과 시간에 방치된 30분이 **더해져 있지 않다**
   (마지막 heartbeat까지만 계산된다). 기록해 둔 세트도 그대로 있다.
6. [재개] 후 종료하면 그 시간만 기록에 남는다.

짧은 전환(2번 뒤 30초 안에 복귀)은 [재개]를 누르지 않아도 자동으로 이어져야 한다.

## E2. 아이콘 / 스플래시

1. 홈 화면 아이콘, 앱 전환기 미리보기, 실행 시 스플래시를 본다.
2. **통과 기준**: Expo 기본 아이콘(흰 배경의 expo 로고, react 로고)이 **보이지 않는다**.
   현재 `assets/images/`에는 템플릿 잔재가 함께 있어 이 확인이 필요하다.

## E3. 권한 안내 문구

1. 히스토리 → [오늘 체중/사진 기록 추가] → 사진 추가.
2. **통과 기준**: 사진 접근 권한 요청이 뜨고 문구가 "몸 형태를 참고할 사진을 고를 때 사진
   라이브러리에 접근해요."로 보인다. **마이크/카메라 권한은 뜨지 않는다.**
3. 설정 → 앱 정보 → 권한에서도 사진 외 권한이 없는지 본다.

## E4. 사진 보관

1. 사진을 넣은 신체 기록을 만든다.
2. 앱을 지우지 말고 **며칠 뒤**(또는 저장 공간을 크게 쓰는 작업 뒤) 히스토리 [몸 변화]에서 다시 연다.
3. **통과 기준**: 사진이 그대로 보인다. 복사가 실패하는 기기라면 **기록은 남고 사진 자리만 비어야
   한다** — 기록 저장 자체가 실패하면 안 된다.

## E5. 빌드 자체

1. 설치가 되고 첫 실행에서 온보딩이 뜬다.
2. **통과 기준**: 크래시 없이 온보딩 4단계를 끝내고 홈이 보인다.

## E6. 화면 크기 / 저사양

1. 세션 화면에서 세트 입력(−/+ 버튼과 숫자 입력), 휴식 타이머 원, [운동 종료] 버튼이
   잘리거나 겹치지 않는지 본다.
2. 시스템 글꼴 크기를 크게 해 두고 같은 화면을 다시 본다.
3. **통과 기준**: 버튼을 누를 수 있고 숫자가 읽힌다.

## E7. 출시 빌드 경계 (이 빌드에서만 확인 가능)

1. 트레이너 탭 → [AI 상담].
2. **통과 기준**: **광고 버튼과 DEV 구독 버튼이 없고**, "광고와 결제를 준비하고 있어요.
   준비되면 여기에서 AI PT를 이용할 수 있어요."만 보인다.
3. 설정 → 구독을 열었을 때도 같은 취지의 문구가 보이고 구독 버튼이 없다.

> 이것이 `FAIL-007`(광고 없이 보상이 나가던 경로)과 `DEC-005`(권리 판정)가 release 빌드에서
> 실제로 지켜지는지 보는 유일한 방법이다. 자동 검증은 소스의 `__DEV__` 경계까지만 본다.
