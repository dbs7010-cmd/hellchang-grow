## 1부 — 개인정보처리방침 초안

### 1. 개요

헬창키우기(이하 "앱")는 사용자가 직접 입력한 운동·신체 기록으로 동작하는 운동 기록 앱입니다.
**앱은 회원가입을 요구하지 않으며 계정을 만들지 않습니다.** 사용자가 입력한 정보는 원칙적으로
사용자의 기기 안에만 저장됩니다.

- 운영자: `{{운영 주체 이름}}`
- 문의: `{{문의 이메일}}`
- 시행일: `{{시행일}}`

### 2. 앱이 다루는 정보

| 구분 | 항목 | 저장 위치 | 수집 방법 |
| --- | --- | --- | --- |
| 신체 정보 | 키, 체중, 체지방률, 골격근량, 체형 선택값, 목표 | 기기 로컬 저장소 | 사용자가 직접 입력 |
| 운동 기록 | 운동 종목, 세트/중량/횟수, 소요 시간, 루틴, 연속 기록, 개인 기록(PR) | 기기 로컬 저장소 | 앱 사용 중 자동 생성 |
| 게임 진행도 | HELL PASS 경험치, 부위별 성장 포인트 | 기기 로컬 저장소 | 앱 사용 중 자동 생성 |
| 사진 | 사용자가 고른 사진의 **기기 내 파일 경로** | 기기 로컬 저장소 | 사용자가 직접 선택 |
| 이용권/구독 상태 | 광고 보상 이용권 수, 구독 기록, 추천인 코드, 이벤트 패스 | 기기 로컬 저장소 | 앱 사용 중 생성 |

앱은 **이름, 생년월일, 전화번호, 이메일, 주소, 위치, 연락처, 광고 식별자를 수집하지 않습니다.**

### 3. 저장 위치와 보관 기간

모든 항목은 기기 내부 저장소(AsyncStorage)에만 보관됩니다. 별도의 서버 계정이나 백업 서버는
없습니다. 따라서 **앱을 삭제하면 저장된 정보도 함께 사라집니다.** 앱 안에서는 설정 화면의
[데이터 초기화]로 저장된 모든 항목을 즉시 삭제할 수 있습니다.

사진은 앱이 복사해 보관하지 않고, 사용자가 고른 사진의 **기기 내 경로만** 기록합니다. 원본 사진은
사용자의 사진 앱에 그대로 있습니다.

### 4. 외부로 전송되는 정보

`{{AI PT 기능을 켤 경우에만 해당}}`

앱에는 AI 트레이너(PT) 대화 기능이 있습니다. **AI 서버가 연결돼 있을 때에 한해**, 사용자가 PT에게
말을 걸면 다음이 전송됩니다.

- 사용자가 입력한 대화 문장과 최근 대화 몇 개
- 답변에 필요한 요약 정보: 키·체중·체지방률·골격근량·목표, 최근 운동 기록과 개인 기록, 진행 중인
  운동 세션 요약, 연속 기록, 사용 중인 루틴

**사진은 전송되지 않습니다.** 전송된 정보는 답변을 만드는 목적으로만 쓰이며, 앱은 서버에 사용자
계정을 만들지 않습니다.

AI 서버가 연결돼 있지 않으면 **어떤 정보도 기기를 벗어나지 않습니다.** 이 경우 PT는 기기에 저장된
기록만 읽어 답합니다.

> 게시 전 확인: 현재 배포 버전에 AI 엔드포인트가 설정돼 있지 않다면 이 절을 "현재 외부로 전송되는
> 정보가 없습니다"로 바꾸고, 기능을 켜는 시점에 이 절을 되살린다.

### 5. 광고와 결제

현재 버전에는 광고 SDK와 인앱결제가 연결돼 있지 않습니다. 광고 식별자를 수집하지 않으며, 결제
정보를 앱이 보관하지 않습니다. 향후 연결하는 경우 이 방침을 먼저 갱신합니다.

### 6. 제3자 제공·처리위탁

앱은 수집한 정보를 제3자에게 제공하지 않습니다. AI PT를 사용하는 경우 답변 생성을 위해
`{{AI 처리 위탁 업체명 / 없으면 이 줄 삭제}}`에 4절의 정보가 전달될 수 있습니다.

### 7. 사용자의 권리

정보가 기기에만 저장되므로, 사용자는 언제든 스스로 열람·수정·삭제할 수 있습니다.

- 열람·수정: 히스토리 탭과 설정 화면
- 전체 삭제: 설정 → [데이터 초기화], 또는 앱 삭제

### 8. 아동의 개인정보

`{{연령 등급 정책 확정 후 작성}}` — 스토어 연령 등급과 함께 정한다.

### 9. 방침 변경

방침이 바뀌면 앱 스토어 등재 정보와 `{{게시 URL}}`에 변경 내용을 공지합니다.

## 2부 — 스토어 답변 시트 (검증된 사실 기준)

### Google Play — 데이터 안전(Data safety)

| 질문 | 답변 | 근거 |
| --- | --- | --- |
| 데이터를 수집하거나 공유합니까? | **AI PT 미연결 시: 아니요** / AI PT 연결 시: 예(건강·피트니스 정보) | 외부 통신은 `remote-trainer-service.ts`의 `fetch` 한 곳뿐이고, 엔드포인트 미설정 시 오프라인 구현이 선택된다 |
| 데이터가 전송 중 암호화됩니까? | 예 (HTTPS 엔드포인트 사용 전제) | `{{엔드포인트 URL이 https인지 확인}}` |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 예 — 앱 내 [데이터 초기화] | 설정 화면 → `resetAllData()` → 14개 키 전부 삭제 |
| 수집 항목 (AI PT 연결 시) | 건강·피트니스: 키/체중/체지방률/골격근량/운동 기록 | `PtContext.profile`, `recentTraining` |
| 사진/동영상 | **수집하지 않음** — 기기 내 경로만 앱에 저장, 업로드 없음 | `photoReference`에 URI만 저장, 전송 경로 없음 |
| 개인 식별자/광고 ID | 수집하지 않음 | 광고 SDK 없음, 계정 없음 |
| 위치·연락처·메시지 | 수집하지 않음 | 해당 권한/코드 없음 |
| 권한 | 사진 라이브러리 읽기 1개 | `expo-image-picker` (마이크/카메라 권한은 명시적으로 차단) |

### Apple — App Privacy 라벨

| 항목 | 답변 |
| --- | --- |
| Data Not Collected | **AI PT 미연결 시 해당** — 앱이 서버로 보내는 데이터가 없다 |

3. 권한 목록에 사진 외 항목이 늘지 않았는가? (`npx expo config --type public`으로 확인)
