## Technical asset requirements

- transparent background for character/action assets unless the asset is explicitly a full scene
- consistent canvas/baseline per family
- stable naming IDs independent of localized display strings
- source/master + runtime derivative distinction
- no text baked into character images
- asset metadata records Character Bible version and status: EXPERIMENTAL / CANON
- final runtime dimensions determined from actual HOME/session/result/world insertion measurements

## Reuse policy

Historical `assets/characters/danbaek/canon/**` is reference-only during rebuild. Reuse technical geometry only if it survives Character Bible 2.0 insertion QA. Never silently label an old asset as new CANON.
